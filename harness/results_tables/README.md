# Result table producers

Every module here exposes `build(exp_root) -> dict`, called once per run by
`harness/results_all_gen.py` (each result cached the first time it is
built) to render `docs/RESULTS_ALL.md`. Nothing under this directory is
archived: `build()` reads this repository's `logs/` and computes its dict
in memory; a module's `main()` can still write that dict to a JSON file for
ad-hoc inspection (`--out-dir`, default `docs/results_tables/` — a
scratch location, not tracked), but the generator never reads such a file.

| module | what it computes | logs it reads | used by |
|---|---|---|---|
| `dev60_cap30.py` | Counterfactual cap-30 accuracy censoring of the dev60 mistral/terra arms (a solve past turn 30 counts as unsolved) | `logs/runs/{mstp_base,mstp_sota_dev60_v2,mstp_evolve,orp_base,orp_sib,orp_evolve}_dev60/results.jsonl` | §2 (pass@1 cells; tail prose: solves lost to censoring, pooled pass@1) |
| `cap30_truncation.py` | Per-attempt cost/wall truncated at the turn-30 boundary from per-call transcripts, and the per-bucket sum/mean | the same six dev60 runs' `results.jsonl` and their attempts' `transcript.jsonl` | §2 ($/solve and wall cells of the mistral/terra rows) |
| `crossfam_rows.py` | A113 mistral held-out rows: pass@1/pass@2/$-per-solve/wall/kill per bucket, plus pooled | `logs/runs/mstf_{base,sota,evolve}_test/results.jsonl` | §3 mistral row |
| `a115_rows.py` | A115b/A116 terra held-out rows, autoform replication counts, and the attribution-partition extension | `logs/runs/orp_{base,sib,evolve}_test/results.jsonl`, `logs/autoform/orp3_{base,evolve,sota}/results.jsonl`, `logs/runs/finisher_only_test/results.jsonl` | §3 terra row, §6 |
| `heldout_table.py` | The held-out miniF2F table (every haiku/sonnet/opus arm, including the opus control's coherent pair, a composite of the A142 rerun and the registered rep 1 — `final_tables.COMPOSITE`, A147), via `harness/final_tables.py`'s own gated computation; also the per-arm CLI-build census (`builds`) and `rows_for(key)` | `logs/runs/FINAL_*/results.jsonl` and the attempts' `transcript.jsonl` init events (via `harness/final_tables.py`) | §3 haiku, sonnet and opus rows; §3 provenance list; `--force` preview banner |
| `autoform_arms.py` | Every non-smoke autoformalization run, grading-corrected and cost-recovered | `logs/autoform/*/results.jsonl` (+ `regrades.jsonl`, `run_meta.json` where present), `harness/autoform_dashboard.py` | §4 table, §4 head prose (kills per family), §7 |
| `audit_verify_rows.py` | A121 post hoc sibling-verified column (registered vs. semantic rep-0 solves per bucket) of the registered runs, haiku comparators included; derives its own bucket assignment from the 16 arms' own `difficulty` fields (no external manifest) | `logs/runs/*/results.jsonl` (the 16 held-out arms), `logs/audit_verify/summary.json` | §3b |
| `common_solved.py` | Post hoc common-solved-pair efficiency: per family (haiku/sonnet/opus/mistral/terra) and bucket, mean $/solve, wall and output tokens per arm over the (problem, slot) pairs all three arms solved (slot = rep as §3 reports it; the opus control's slots are the A142 rerun and the registered rep 1; wall-killed pairs dropped and counted) | `logs/runs/{FINAL_pf_*_haiku,FINAL_frozen_wallonly,FINAL_pf_*_sonnet,FINAL_pf_*_opus,FINAL_pf_baseline_opus_r245,mstf_*_test,orp_*_test}/results.jsonl` and, for Mistral rows, their attempts' `transcript.jsonl` | §3c |
| `finisher_partition.py` | A114 finisher-only solve set and its overlap partition against the held-out arms | `logs/runs/{finisher_only_test,FINAL_pf_session2_sonnet,FINAL_pf_baseline_sonnet,FINAL_pf_rocqmcp_sonnet,mstf_evolve_test,mstf_base_test,mstf_sota_test}/results.jsonl` | §6 |
| `heldout_cost_recovered.py` | Sonnet held-out $/solve under the recovered-cost convention (wall-killed attempts priced from their transcript usage) | `logs/runs/FINAL_pf_{baseline,rocqmcp,session2,session}_sonnet/results.jsonl` and their attempts' `transcript.jsonl` | cited in §3 prose (descriptive; not a table cell) |
| `paired_tests_pooled.py` | Pooled two-test-per-family exact McNemar with Holm adjustment (sonnet, haiku A118, opus A147 with the A142 control rerun, mistral, terra, and the registered-rep-0 opus contrast `opus_rep0`), ported (pooled-family part only) from a sibling archive's `paired_archive.py` | rep-0 rows of `logs/runs/{FINAL_pf_session2_sonnet,FINAL_pf_baseline_sonnet,FINAL_pf_rocqmcp_sonnet,FINAL_frozen_wallonly,FINAL_pf_baseline_haiku,FINAL_pf_rocqmcp_haiku,FINAL_pf_session2_opus,FINAL_pf_baseline_opus_r245,FINAL_pf_baseline_opus,FINAL_pf_rocqmcp_opus,mstf_*_test,orp_*_test}/results.jsonl` | §5 |
| `rail_census.py` | Cap-termination census for one run (non-solved rows whose `num_turns == max_turns`), ported (single-run form) from a sibling archive's `rail_census.py` | `logs/runs/<run>/results.jsonl`, `run_meta.json` | §3 head prose (mistral evolve test arm's cap-100 rail count) |
